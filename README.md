# excel-primary-care-dashboard
Interactive Excel dashboard project for a primary care clinic using Power Query, PivotTables, and data modeling.  Includes a realistic synthetic healthcare dataset (patients, doctors, appointments, visits), full data cleaning workflow,  KPI calculations, and a dynamic dashboard for analyzing patient flow and clinic performance.
